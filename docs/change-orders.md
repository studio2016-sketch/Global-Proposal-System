# Change orders

Never edit an accepted commercial snapshot.

Post-acceptance additions, reductions or substitutions become change orders referencing the base snapshot hash. A change order has its own scope, financial delta, version, owner approval, client approval/signature/payment lifecycle and audit history.

Examples include added LED, extra production days, additional musicians, upgraded backline, extended consulting scope, instrument specification changes, travel changes or venue-driven technical requirements.

Once a change order is fully approved and any required closing conditions are met, operations applies it as an amendment while preserving both the original accepted snapshot and the change-order record.
