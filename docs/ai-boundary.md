# AI authorization boundary

AI is a drafting system, never a commercial authority.

Allowed: summarize discovery, identify missing facts, draft narrative, recommend approved catalog items, propose options, explain rationale, draft follow-up copy.

Requires deterministic/server validation: prices, quantities, dependencies, discounts, deposit, recurring totals, tax, travel rules.

Requires owner action: approving a proposal version, overriding price, publishing/sending, approving non-catalog commercial terms.

A generated draft always begins in DRAFT. AI output cannot set APPROVED_TO_SEND, SENT, SIGNED, PAID or ACTIVATED.
