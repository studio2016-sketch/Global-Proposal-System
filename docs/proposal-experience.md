# Proposal experience

A proposal is a branded private web experience, not a PDF rendered in a browser.

Core composition: cinematic hero; client-specific vision; recommended architecture/experience; scope; media where useful; interactive investment; timeline/path to delivery; clear next action.

The client may configure only options already authorized in the approved proposal version. The browser submits IDs and quantities; it never submits trusted prices. The server retrieves authoritative commercial terms and recalculates totals.

If the owner revises commercial terms after a proposal is sent, a new version is created. Prior authorization does not carry forward.

Future brand-domain rewrites can present the same engine at brand-native URLs while the shared system remains the source of commercial truth.
